
# EVORA CODE V2

A professional mobile-friendly code editor built with React, Vite and CodeMirror.

## Features

- HTML, CSS, JavaScript and JSON editing
- Syntax highlighting
- File explorer
- Create and delete files
- Live HTML preview
- Mobile and desktop preview
- JavaScript console
- Automatic local saving
- Export project as ZIP
- Responsive interface

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production Build

```bash
npm run build
```
